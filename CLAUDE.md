# libastromech

Monorepo of implementations (`python/` and `esp32/`, with `java/` and `c/` planned), each independently buildable and deployable. Nothing outside an implementation's own directory may be required to build it. Shared docs/images live in `docs/`.

**Config:** `config/` (top level) is the source of truth for droid/personality YAML. Each implementation keeps a committed copy (Python: `python/src/config/`; ESP32: `esp32/config/` plus the generated `esp32/src/astromech_config.h`) so it stays self-contained. Edit only `config/`, then run `make sync-config`; `make check-config` (part of `make test`) fails on drift.

**Make targets:** `make build`, `make test`, `make <python|java|c|esp32>-build|-test|-clean`, `make python-dist-check` (test, clean rebuild, `twine check`; no upload), `make python-deploy` (same, then prompts and uploads to PyPI via twine; `REPO=testpypi` for TestPyPI, `CONFIRM=yes` skips the prompt). Never run `python-deploy` without the user's explicit go-ahead: uploads are irreversible and the version in `python/pyproject.toml` must be bumped first.

**ESP32** (`esp32/`, Arduino + PlatformIO + NimBLE-Arduino 2.5.x; see `esp32/README.md`): one board per droid, a separate board for the beacon. `src/astromech_protocol.*` is pure encoding (host-tested via `make esp32-test`); `Astromech`/`R2Unit`/`BBUnit`/`Beacon` are the BLE layer. `astromech_config.h` is generated by `esp32/tools/gen_config.py` (run by `make sync-config`), so never hand-edit it. Toolchain is `pio` from `/opt/esp-venv`. The beacon status byte follows the Python code (`0x01`, `0x81` when paired), not the notes' example table.

The sections below describe the Python implementation, rooted at `python/`. Python library for controlling Star Wars: Galaxy's Edge astromech droids over Bluetooth Low Energy (BLE).

## Architecture

- `python/src/libastromech/astromech.py` - Base `Astromech` class with BLE connection management, command protocol encoding, motor control, and audio playback. Uses `bleak` for BLE communication.
- `python/src/libastromech/r2.py` - `R2_Unit` subclass with R-Series-specific methods: head rotation, center head, look around, differential drive (forward, backward, spin, turn, drift).
- `python/src/libastromech/bb.py` - `BB_Unit` subclass with BB-Series-specific methods: forward/backward movement and head rotation via body spin.
- `python/src/libastromech/beacon.py` - BLE beacon broadcasting via `hcitool`/`hciconfig` subprocess calls. Supports location and personality beacon construction, start/stop, and a long-running `run_beacon()` async loop.
- `python/src/libastromech/__init__.py` - Public API re-exports: `Astromech`, `Direction`, `Personality`, `Sound`, `R2_Unit`, `BB_Unit`, `location_beacon_payload`, `personality_beacon_payload`, `run_beacon`, `start_beacon`, `stop_beacon`.

## Config

- `python/src/config/droids/r2.yml` and `bb.yml` - Motor speed and ramp time defaults per droid type.
- `python/src/config/personalities/*.yml` - Sound banks (group, sound index, duration in ms). Named by personality chip color + affiliation.

## Key Concepts

- Droids connect as async context managers (`async with R2_Unit(...) as droid:`). The `__aenter__` handles BLE connect, notification subscription, and the double-login handshake (`0x222001` x2).
- Commands are written to GATT characteristic handle 13 (Command Characteristic `0x000e`). Notifications come from handle 10 (Notify Characteristic `0x000b`).
- Command encoding: `[0x1f + 4 + data_len, 0x42, command_id, 0x40 + data_len, ...data]`. Audio commands use command ID `0x0f` with sub-function byte `0x00`. Motor commands use command ID `0x05`.
- `Sound` objects store group, sound index, and duration (ms). `Personality` loads these from YAML config files.
- `keep_alive()` periodically reconnects and pings, calling success/failure callbacks.

## Build & Install

```bash
cd python
pip install -e .
```

Package is built with setuptools via `pyproject.toml`. Requires Python >= 3.9, `bleak>=0.22.3`, `PyYAML>=6.0.2`.

## Known Droid MAC Addresses

- R2-T2: `F7:E6:74:95:E5:53`
- BB-12: `E6:1C:86:B3:BD:AE`
